# Personal Portfolio Website

A modern, responsive personal portfolio website built to highlight my work and skills as a Frontend Developer.

## 🚀 Features
- **Responsive Navigation:** A custom-built, mobile-friendly navbar with a functional hamburger menu.
- **Dark Mode Aesthetic:** A clean, professional dark UI with high-contrast accents.
- **Project Showcases:** Sections dedicated to experience, services, and my development journey.
- **Interactive Elements:** Smooth transitions and JavaScript-powered components for enhanced user experience.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **Tailwind CSS:** Utility-first styling for rapid, responsive design.
- **JavaScript (ES6+):** Dynamic functionality and menu logic.

## 📂 Project Structure
- `/src`: Contains the main source code files.
- `/img`: Optimized images and assets.
- `portfolio.html`: The main entry point for the website.
